# Contract examples

The machine-readable contracts moved to `shared/` (spec `002-platform-split`, FR-005 and FR-007):

- the JSON schemas: `shared/contracts/*.schema.json`
- the play sheet, storyboard and script examples: `shared/contracts/examples/`
- the style packs and the voice registry: `shared/styles/`

The example style packs that used to sit in `styles/` here had drifted from the live packs and were removed; the live packs in `shared/styles/` are the examples.
