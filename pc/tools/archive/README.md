# Archived spikes

Not maintained. These scripts are the one-off spikes of 001 (T002, T003, T004, Z1) and the agent-core vision example, kept for the record that `docs/api-notes.md`, `docs/provider-notes.md` and `docs/chinese-language.md` cite. They still use the repository layout from before spec `002-platform-split` (a `REPO` constant, `src/`, `assets/`, `eval/spike/` at the root), so they do not run as they are.

Their outputs are in `pc/eval/spike/`. The maintained tools are one level up: `spotter_check.py`, `make_test_clip.py`, `make_sound_library.py` and `make_conformance.py`.
